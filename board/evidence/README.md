# 上板照片证据说明

`photo_01` 至 `photo_04` 为提交者提供的真实实验照片。可见 PYNQ-Z2、外接控制板与电机、示波器、状态显示和笔记本终端的同步运行场景。其中示波器显示重复脉冲波形，串口终端显示持续输出状态字段。照片没有附带原始仪器导出 CSV、BIT/ELF 哈希的现场照片或逐项传感器参考值，因此不把照片推断为示波器频率误差、转速绝对准确率或 4096 点 DMA 完整帧的独立定量证明。

项目队伍确认优化版已完成板级功能验证；若正式评分要求外部参考结果对比，应补充可读的仪器频率数值与系统同时刻 RPM 数据，以及完整 DMA 捕获/状态记录。

参考表见 `data/board_reference_matrix.csv`。
