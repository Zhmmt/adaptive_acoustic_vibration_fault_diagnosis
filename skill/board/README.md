# 上板回归与证据采集

适用：优化硬件已导出 BIT/HWH/XSA，希望复用既有裸机 ELF 的项目。

1. 记录 BIT、XSA、ELF 的 SHA-256，备份已验证的旧组合。
2. 断开电机功率，先检查 PS 启动、UART、控制字、ADXL345 DEVID 和 IIC 读回。
3. 检查按键/ESTOP、25 kHz PWM（以示波器实测为准）、HC-020K 转速与 LCD 显示、双通道音频和 DMA。
4. 对每个项目保存条件、预期、观测、参考测量方法与原始日志；照片不替代仪器测量记录。
5. 再通电做安全转速试验，绝不将传感器的 5V 输出直接输入 3.3V FPGA IO。

RS555 HWH 使用 14 位 DMA S2MM 长度字段，应用帧缓冲为 4096×4=16384 字节。该边界条件需要实际确认或附加分段/参数修正测试。不得仅以串口有音频状态字就认定完整帧 DMA 传输可用。

**失效条件**：变更 XSA 后 ELF 未重建或未核对宏、不同 BIT 的照片混用、没有仪器来源的数值被写成测量值、电机未采取物理断电保护。
