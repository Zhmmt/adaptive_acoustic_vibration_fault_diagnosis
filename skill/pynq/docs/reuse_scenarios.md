# 通用 PYNQ Skill 跨题目应用场景与复用方法

本技能面向 **HWH 接口元数据 / AXI-Lite 寄存器 / simple S2MM DMA / 定长数据文件**，而非绑定特定电机或声振故障检测算法。以下为可迁移的工程场景，不等同于已经在这些设备上完成上板验证。

| 场景 | 可直接复用的部分 | 需要针对目标工程替换或验证的内容 | 验证状态 |
|---|---|---|---|
| 风机、泵站的振动与噪声采集 | Overlay IP 清单、AXI 地址审计、DMA 接收容量检查、原始样本完整性校验 | 传感器协议、数据宽度、采样率、通道打包与诊断规则 | 待目标硬件验证 |
| 输送机、电机与轴承监测 | GPIO 状态映射和寄存器安全读、DMA 数据抓取 | 转速源、同步策略、异常阈值及执行机构安全条件 | 待目标硬件验证 |
| 声学阵列/环境噪声记录 | AXI-Stream 接收、PCM 数据长度及通道格式校验 | 声道数、字节序、位宽、TLAST 规则、信号质量评价 | 待目标硬件验证 |
| 通用 AXI GPIO/计数器教学工程 | HWH 解析、离线契约、参数不匹配检查 | GPIO 方向、地址和复位值 | **已有另一 GPIO HWH 的离线 PASS/故意失败验证** |
| 其他 Zynq/PYNQ 板卡的 Overlay 工程 | HWH/BIT 配对审计、可配置合约和接口日志 | 对应 PYNQ 软件版本、IP 驱动、物理外设接线、安全条件 | 尚无跨板卡上板记录 |

## 通用迁移步骤

1. 输入目标设计同一构建产生的 BIT 和 HWH，重新生成契约草稿并人工审核，切勿保留 RS555 固定 AXI 地址。
2. 先执行不访问物理设备的离线接口审计；确认 IP、地址、DMA 模式和长度位宽。
3. 在目标 PYNQ 板卡确认电源与外设安全后下载 Overlay；优先只读方式验证寄存器。
4. 仅在确认帧大小、TLAST、TKEEP、缓存同步和 reset 规则后运行 DMA 接收；保存原始二进制、运行日志、版本与摘要。
5. 需要 golden reference 时以该任务的已知输入建立独立样本，严禁复用 RS555 音频样本作为新系统正确性证明。

## 失效条件

Scatter-Gather DMA、MM2S 发送、不同数据封包、无 TLAST 流、驱动不兼容、Linux 无法启动、外设电压不匹配等场景均不在原始上板验证结论内。请先按 `troubleshooting.md` 排障，再独立建立验证记录。
