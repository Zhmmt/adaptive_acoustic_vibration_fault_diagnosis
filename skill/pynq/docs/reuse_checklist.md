# 更换工程或板卡的迁移检查清单

- [ ] 明确板卡/芯片型号及 Linux、PYNQ、Vivado/Vitis 版本；不把 PYNQ-Z2 的实验条件视作通用保证。
- [ ] 保存新的同次构建 BIT/HWH/XSA 及构建日志；文件同名不足以证明配对。
- [ ] 用 `overlay_audit.py` 获取 HWH 实例名、地址、参数；以经人工审核的新 JSON 契约检查后续变更。
- [ ] 检查 GPIO 的方向、复位值、可读/可写偏移、保留位、外部执行机构安全条件。
- [ ] 在 PYNQ 环境先执行 `Overlay(..., download=False)`，对不存在 `phys_addr` 的条目做显式处理。
- [ ] 仅当外部设备安全且无其他 PS 软件/JTAG 并行控制时，才允许显式下载 BIT。
- [ ] DMA 先核对模式、方向、数据宽度、TLAST、TKEEP、缓存一致性、接收地址和最大长度；计算 `frame_bytes <= (1 << length_width) - 1`。
- [ ] 只有在确认接收通道停止或成功完成后才释放缓冲区；故障与超时须规定安全复位策略。
- [ ] 使用与实际流格式一致的黄金样本检查字节序、有符号扩展及通道排列。
- [ ] 保留原始输入、执行代码、输出、版本信息和 SHA-256；分别标明离线、板端、整机及跨板卡测试状态。
- [ ] 如硬件中没有音频流，可只复用 HWH、AXI 地址和状态检查工具，不应照搬 RS555 PCM 数据约定。

**迁移验收定义**：在新项目中独立证明元数据契约核对通过，并对项目需要的功能给出真实运行输出。未在该项目上测试的脚本应保持“待验证”状态。
