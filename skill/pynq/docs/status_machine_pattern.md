# 传感器基线与故障状态判定的可复用设计范式

## 适用范围

适用于多传感器监测系统中，需要在变速/变负载条件下进行异常判断，且必须明确区分数据缺失、未校准、稳定过渡、正常和异常的项目。以下参数是 RS555 新版 `main.c` 的**具体实现值**，移植时按目标设备的正常工况重新采样，不可当作通用固定阈值。

## 案例中的基线组织方法

- 转速范围按 `RPM_BUCKET_SIZE=200` 分组、`RPM_BUCKET_COUNT=25` 分桶，基于当前 RPM 或就近有效转速桶取得振动与声音的正常基线。各桶至少 5 次振动样本、5 次声音样本才可使用。
- 转速过载判断使用 `PWM_BUCKET_COUNT=21` 对应 `0%、5%、…、100%` 的**实际物理按键选定 PWM**。必须在当前同一档位取得至少 5 次正常 RPM 样本，且基线不低于 200 RPM，才允许形成转速参考；不得拿相邻档位转速代替。
- 正常训练条件包括电机实际运行、传感器有效、已有至少 2 次加速度读数、RPM ≥100 且当前转速处于稳定阶段。需要用户明确输入 `n` 进入校准；不会在普通监测中自动学习异常数据。
- 数据为 RAM 中的累计和/计数，校准结果未在当前 C 源中写入非易失存储；重新启动程序后须重新取得基线。大于 1000 次样本时，当前实现通过对和与计数减半抑制数值持续增长。

## 判断流程与失败边界

1. ADXL345 读取失败或初始化失败：将 ready 清零、状态设为 `SENSOR_ERROR`；不能把振动零值作为正常证据。
2. 电机未运行、PWM 小于 15%，或没有足够的加速度差分样本：状态保持未知，不进行完整正常判定。
3. BTN3 新启动后稳定窗口约 1.2 秒；PWM 变化后约 0.8 秒。窗口内不把短时过渡当成持续异常，也不在尚未形成证据时输出 NORMAL。
4. 同一 PWM 档位的 RPM 相对于正常基线连续 5 次下降至少 15%，触发 `g_speed_fault`；上升到正常基线的 92% 或以上并连续 5 次确认后解除。中间灰区用于滞回，避免阈值附近抖动。
5. 振动阈值：高阈值为振动基线上增加 100% 的幅度（增加量下限 30）；低恢复阈值为增加 60% 的幅度（增加量下限 30）。声音取两路幅值最大值，高阈值增加 60%、低恢复阈值增加 40%（增加量下限同为 30）。高阈值连续 3 次，或两者同时高阈值连续 2 次，可形成对应告警。
6. **NORMAL 的必要条件**：当前工况有完整的振动/声音参考以及同一 PWM 档位 RPM 参考；无速度故障；连续 3 次符合正常判定条件。处于 ABNORMAL 状态时，恢复还要求振动和声音同时低于各自较低的恢复阈值。
7. 任意有效证据可导致异常：例如缺少振动/声音参考时，如果有同 PWM 的有效速度参考且速度持续下降，仍可触发速度异常；但不可在证据不完整时宣称整机 NORMAL。

## 输出状态和物理动作必须分开

串口状态文本包括 `STOPPED`、`SETTLING`、`NO_PWM_BASE`、`CHECKING`、`NORMAL`、`ABNORMAL`、`SENSOR_ERROR`，其作用是表达检测条件是否满足。LCD 故障覆盖使用 `CTRL_OVERRIDE` 与 `CTRL_FAULT`，与状态文本不是完整的一一对应。特别是没有覆盖状态时，RTL 仍可能使用本地阈值作为 LCD 备用显示依据。

本例的异常检测只影响软件状态和 LCD 故障显示，不构成电机自动断电保护链。物理 BTN2 STOP、软件 ESTOP 和外部功率断电属于不同层级的安全手段。

## 可复用的工程原则

- **未知不等于正常**：缺少传感器或基线时不能输出具有误导性的正常结论。
- **训练条件必须显式**：只允许在操作人员确认的正常工况下积累参考。
- **跨工况基线不得任意替代**：尤其是速度-占空比关系随负载变化时。
- **报警与恢复使用不同阈值**：并以连续样本消除瞬态抖动。
- **可追踪的状态优于单个“正常/异常”位**：将传感器错误、稳定阶段、基线缺失和实际报警区分。
- **阈值属于标定结果而非固定真理**：需要板端正常/异常样本、误报率、漏报率和响应时间来评估合理性。

上述归纳依据为所给新 C 源的静态代码，不代表已经用当前硬件完成定量诊断性能评价。
