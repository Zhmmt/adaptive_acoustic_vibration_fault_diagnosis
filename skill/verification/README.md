# RTL 黄金参考与有效信号回归

适用：有同步数据流、滤波器流水线、整数运算替换、AXI-Stream 帧控制的 FPGA 工程。

1. 固化原始运算的位宽、符号与溢出/饱和规则；参考模型不可仅比较浮点近似。
2. 以输入有效周期和输出有效周期形成成对断言；延迟增加后不可只比较同一时钟的 `dout`。
3. 增加复位、空闲保持、负值、饱和边界、间隔样本、通道同步和 TLAST 测试。
4. XSim 输出每个测试的明确 PASS 标记及失败返回码；使用 `tools/simulation_gate.py` 检查完整日志。

RS555 完整构建使用 `scripts/run_hdl_tests.bat`，包含 FIR31、LCD BCD、测速等价、DC Blocker、双声道集成五项。首次仿真曾出现 `VALID_FAIL idx=0`；原因是工程同时引用原版和新版 `fir31.v`，应先列举所有引用源再判断算法是否失效。

**失效条件**：缺少完整 runtime log、只通过编译未运行、黄金参考算法和 DUT 使用相同有缺陷表达式、采样间隔不满足多周期模块前提。
